# Privacy Policy

NeumoTab does not collect, store, or transmit personal information, analytics data, or telemetry.

## Local settings

NeumoTab stores search engines, shortcuts, and other settings using the browser's local storage.

NeumoTab does not upload these settings to any server.

Settings can also be exported and imported as JSON. These files are handled locally by the user.

## Favicons

NeumoTab may request `/favicon.ico` from websites configured as shortcuts in order to display their favicons.

These requests are made directly by the browser to the respective website. The website may receive normal connection information such as the user's IP address.

NeumoTab does not receive or store this information.

## Search engines

When you perform a search, your query is sent directly to the search engine you selected.

NeumoTab does not collect or proxy search queries.

## Custom HTML and JavaScript

NeumoTab provides a Console API for advanced customization. Code executed through this API is controlled by the user and may access external resources or perform other actions according to the permissions available to the page.

Such activity is not collected or transmitted by NeumoTab.

## Changes

This privacy policy may be updated when the functionality of NeumoTab changes.

## Contact

For questions or issues, please use the [GitHub repository](https://github.com/sudachi443/NeumoTab).
